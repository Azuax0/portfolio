APC22 Mobile Ops

Application compagnon pour la Protection Civile afin de saisir les interventions, partager les checklists et synchroniser avec le poste de commandement même en connectivité limitée.

Années : 2023 — 2024
Client : Protection Civile Côtes-d’Armor
Rôle : Développeur principal & co-designer
Objectif

Centraliser les fiches d’intervention et briefings terrain dans une application mobile utilisable hors ligne, avec synchronisation sécurisée dès le retour réseau.

Défis clés
  • Garantir la capture de données en mode avion et gérer les conflits lors des synchronisations.
  • Proposer une interface intuitive pour des secouristes centrés sur l’intervention.
  • Assurer la conformité RGPD et les contrôles d’accès pour les exports sensibles.
Contributions
  • Ateliers avec les équipes APC22 pour prioriser les parcours terrain.
  • Développement Flutter (états, formulaires dynamiques, mode offline) avec règles Firebase Auth/Firestore.
  • CI/CD GitHub Actions et distribution sécurisée via Firebase App Distribution.
  • Exports PDF automatiques et passerelle FastAPI pour le reporting coordinateurs.
Stack & outils
  • Flutter, Dart, Riverpod
  • Firebase Auth, Firestore, Cloud Functions
  • FastAPI, PostgreSQL pour les exports historiques
  • GitHub Actions, Firebase App Distribution
Impact

Pilotée sur des exercices départementaux : réduction du papier, préparation accélérée des bilans post-intervention et traçabilité renforcée pour l’encadrement.

Urgent Care Print Dispatcher

Chaîne d’impression automatique inspirée du SAMU pour diffuser fiches patients et prescriptions aux maisons médicales de garde sans action manuelle.

Année : 2023
Contexte : Maisons médicales de garde
Rôle : Développeur & intégrateur systèmes
Objectif

Garantir la diffusion fiable de documents critiques (fiches patients, prescriptions) depuis e-mails et API vers plusieurs imprimantes.

Défis clés
  • Gérer les files d’attente et prioriser selon l’urgence.
  • Surveiller les périphériques et relancer automatiquement.
  • Sécuriser les documents (chiffrement, purge post-impression).
Contributions
  • Service Python avec watchdog filesystem et API IMAP pour collecter les ordres.
  • Pipeline CUPS, règles d’impression et scripts Bash pour les scénarios de secours.
  • Dashboard Grafana + alertes Telegram pour surveiller les blocages.
  • Documentation d’exploitation et procédures de reprise.
Stack & outils
  • Python, CUPS, systemd
  • Grafana, Prometheus, Alertmanager
  • IMAP, PDFtk, Bash
Impact

Impressions toujours dans les temps, même hors horaires de bureau, et alertes proactives limitant les interventions sur site.

Presence-Aware TV Signage

Réseau d’écrans pilotés par Raspberry Pi qui s’activent à l’arrivée du personnel et diffusent automatiquement les tableaux de bord opérationnels.

Année : 2022
Contexte : Protection Civile & locaux associatifs
Rôle : Intégrateur IoT
Objectif

Optimiser l’affichage des informations critiques (planning, météo, consignes) en réduisant la consommation électrique des écrans.

Défis clés
  • Détecter la présence avec capteurs PIR calibrés par salle.
  • Synchroniser dashboards, flux vidéo et alertes sans intervention.
  • Durcir le réseau et sécuriser physiquement les boîtiers.
Contributions
  • Scripts Bash/Python pour HDMI-CEC, rotation des sources et redémarrages planifiés.
  • Serveur MQTT + Node-RED pour la gestion du parc et les alertes.
  • VLAN dédié, VPN WireGuard, durcissement (fail2ban, audits Lynis).
  • Documentation de déploiement pour installation par bénévoles.
Stack & outils
  • Raspberry Pi OS, Python, Bash
  • MQTT, Node-RED, Grafana
  • VLAN, VPN WireGuard
  • HDMI-CEC, capteurs PIR
Impact

Affichage activé uniquement lorsque nécessaire, réduction de la consommation et mise à jour centralisée des informations critiques.
